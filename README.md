# homebrew-tap

Homebrew tap for [local-review](https://github.com/mshykov/local-review) — a local, BYOK AI code reviewer with multi-LLM support.

## Install

```sh
brew install mshykov/tap/local-review
```

## Usage

See the [main repo](https://github.com/mshykov/local-review) for documentation.
